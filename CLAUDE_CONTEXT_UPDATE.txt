## 2. NEW FEATURES MERGED (Felix 22.0 + Felix 22.1)

### Felix 22.0 — Attendance Sheet (merged to main)

Upgrades the Teacher Dashboard from a simple student list into a **class-based Attendance Sheet**:

- **`schedule_students` table** added to DB: `schedule_id` → `schedules.id`, `student_id` → `students.id`, `enrolled_at`. PK = (schedule_id, student_id). ON DELETE CASCADE for both FKs.
- **Migration**: on first run after adding the table, every existing student is enrolled in every existing schedule (`INSERT OR IGNORE`).
- **GET `/students/attendance-sheet?schedule_id=&date=`** — Full class roster with attendance status (present/absent) for one class on one date.
- **POST `/students/import/csv?schedule_id=`** — Bulk-import/roster students from CSV (name, nim, mac_address). Existing NIMs are reused and enrolled instead of duplicated.
- **GET `/students/export/xlsx?schedule_id=&date=`** — Download full roster + attendance result as formatted `.xlsx` file.
- **POST `/students/{id}/schedules/{sid}`** — Enroll student in a schedule.
- **DELETE `/students/{id}/schedules/{sid}`** — Remove student from schedule roster (keeps global profile + history).
- **GET `/schedules/export/csv`** — Export all schedules as CSV.
- **POST `/schedules/import/csv`** — Import schedules from CSV (columns: class_name, day/day_of_week, start_time, end_time, room, ap_bssid).
- Dashboard now has two tabs: **Student List** (full roster with green/red indicators) and **Attendance Record** (submitted attendance with start/end times dialog).

### Felix 22.1 — Dashboard Efficiency + Schedule CSV Tools (merged to main)

Refines the Attendance Sheet from Felix 22.0:

- Removed duplicate attendance sheet labels and redundant card headers.
- Added modern date control with calendar icon, focus/hover/border states.
- Schedule import/export now on the Schedules page (Import CSV + Export CSV buttons beside Add Schedule).
- Import validation: skips invalid rows, duplicates, and room/time conflicts; reports skipped rows.
- Includes automated tests for all new features.
