02 / HOW IT DECIDES

A selfie alone is not enough. The device must be on the school network, the scanned token must belong to the current phase, and the face must match the logged-in student. A phase change issues a new token, so an old QR stops working immediately.

01 · Network 02 · QR token 03 · Face + liveness 04 · Identity bound

The token rotates every 5 s and the previous one stays valid for 10 s. A 403 means the client IP is outside SCHOOL_SUBNET and no row is written. A face that matches another student is also a 403 with no row. The roster collapses the rows into verified, partial, pending or absent.
